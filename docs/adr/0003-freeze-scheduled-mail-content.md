# 예약 메일은 생성 때 내용을 확정하고 발송 직전에 대상 자격만 확인한다

예약 뒤 템플릿이나 지원 상태가 바뀌면 운영자가 예약한 내용과 실제 발송 내용이 달라질 수 있다. 사용자 결정에 따라 대상·주소·렌더링된 제목·본문은 예약 때 확정하고 유지하며, 발송 직전에는 자격을 다시 확인해 조건을 벗어난 대상만 제외하고 사유를 남긴다. 최신 템플릿으로 다시 렌더링하지 않아 운영자가 예약한 내용을 보존하되, 변경된 대상의 제외 기준은 실행 기능 구현 전에 확정한다.

한국 시간은 시간대가 포함된 입력으로 받아 UTC 시각으로 저장한다. 취소는 발송 처리 시작 전까지만 허용하고, 장애로 예약 시각을 놓치면 복구 후 지연 발송한다. 전원이 제외되면 0건 발송으로 종료하고 전원 제외 사유를 보여준다.

2026-10-06 현재 생성·저장·조회만 구현한다. `SCHEDULED` 작업은 기존 worker와 claim 대상에서 제외하며, 이 ADR 자체가 자동 발송·취소·대상 재검증의 구현 완료를 의미하지 않는다. 불확실 발송 결과의 자동 재발송 금지는 ADR 0002를 유지한다.

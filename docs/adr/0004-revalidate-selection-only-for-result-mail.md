# 선정 결과 변경은 결과 안내 예약에서만 제외 기준으로 사용한다

2026-10-20 사용자 승인에 따라 예약 이후 선정 결과 변경은 합격·예비 합격·불합격 등 결과 안내 메일에서만 대상 제외 기준으로 사용한다. 일반 안내는 선정 결과 변경만으로 제외하지 않는다. 모든 예약의 삭제·반려 등 기본 자격 확인과 제외 사유 기록은 유지하며, 예약 시 확정한 내용은 다시 생성하지 않는다.

ADR 0003의 내용 확정·취소·지연 발송 정책은 유지한다. 이 결정은 자격 재검증의 적용 범위를 확정한 것이며 자동 실행 구현 완료를 뜻하지 않는다.
